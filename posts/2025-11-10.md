Published [qstr](https://github.com/tindzk/qstr), a Rust library for cache-efficient, stack-allocated string types.

Example:

```rust
use qstr::BStr15;
use qstr::StrVec;

let str: BStr15 = "aws:us:east:1".into();
let vec: StrVec<u16, 15> = str.split(":");

assert_eq!(
  vec.iter().collect::<Vec<_>>(),
  vec!["aws", "us", "east", "1"]
);
```
